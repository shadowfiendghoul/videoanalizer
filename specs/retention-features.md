# Спецификация: Вирусные механики и удержание аудитории (Retention Mechanics) для Quiz Shorts

Документ описывает набор психологических и интерактивных механик удержания внимания (Retention Rate) и виральности (Share & Comment Velocity) для вертикальных викторин формата 9:16 (TikTok, YouTube Shorts, Instagram Reels).

---

## 🎯 Цели и ключевые метрики (KPIs)

1. **Average Percentage Viewed (APV)**: целевой показатель $> 100\%$ (за счет бесшовного лупа и прогрессирующего темпа).
2. **Completion Rate**: увеличение досмотра до 9-го вопроса с текущих $35\%$ до $\ge 65\%$.
3. **Comment-to-View Ratio**: повышение активности в комментариях в 3–5 раз через ловушки споров и байтинг самолюбия.
4. **Re-watch Rate**: стимуляция повторных просмотров через микро-подсказки и быстрый темп финала.

---

## 🧩 Обзор вирусных механик

| # | Механика | Психологический триггер | Влияние на удержание |
|---|---|---|---|
| **1** | **IQ / Rank Status Bar** | Социальный статус, геймификация | Удерживает интерес до финала ради получения высшего ранга |
| **2** | **Stress Timer (Паника)** | Дефицит времени, адреналин | Исключает скуку, ускоряет динамику к 9-му вопросу |
| **3** | **Streak Fire (Комбо-стрик)** | Азарт, серийность (Duolingo effect) | Создает эффект личной игры («сколько выбью подряд?») |
| **4** | **Comment Trap (Ловушка споров)** | Уязвленное эго, контринтуитивность | Взрывает алгоритмы волной комментариев |
| **5** | **Seamless Loop Hook** | Неосознанный перезапуск | Дает удержание $>100\%$ в TikTok/Reels |
| **6** | **Decoy Fake-Out (Ложный ответ)** | Эмоциональные качели (Surprise) | Разрушает стереотипы, заставляет пересматривать |
| **7** | **Glitch Peek Hint (Слепая подсказка)** | Микро-дофамин, внимательность | Стимулирует пересматривать кадр |
| **8** | **Anti-Cheat Callout (Челлендж честности)** | Живой контакт, вызов авторитета | Предотвращает паузы и вовлекает в соревнование |

## 1. Психологическая шкала статуса (IQ / Brain Rank Bar)

### 1.1. Концепция и психология
Человек не хочет ассоциироваться с низким социальным статусом («NPC», «Двоечник»). По мере прохождения квиза шкала заполняется, и зритель физически ждет 9-й вопрос, чтобы увидеть присвоение статуса «1% Гениев».

### 1.2. Визуальное поведение (Remotion)
- **Расположение**: Горизонтальная статусная полоса в верхней части экрана (Y = 160px, прямо над `LevelHeader` в безопасной зоне TikTok).
- **Градация рангов**:
  - Вопросы 1–2: **«🤡 NPC / Мозговой туман»** (Серый `#64748B`, плоская шкала).
  - Вопросы 3–5: **«🤓 Нормис / Эрудит»** (Изумрудный `#22C55E`, неоновый контур).
  - Вопросы 6–8: **«🧠 Магистр / Гигачад»** (Фиолетовый `#A855F7`, частицы свечения).
  - Вопрос 9: **«👑 1% ГЕНИЕВ / Эйнштейн»** (Золотой `#F59E0B` + переливающийся градиент и эффект лучей света).
- **Анимация**: Плавное заполнение полосы через `spring()` после каждого правильного ответа. При смене статуса — микро-взрыв золотых искр (Remotion SVG-частицы) и увеличение бейджа ранга в 1.2x с отскоком.

### 1.3. Аудио-эффекты (SFX)
- Прирост шкалы: короткий восходящий арпеджио-клик (`rank_tick.wav`).
- Повышение ранга (Level-Up): мощный «Cosmic Chime + Sub-Bass Boom» (`rank_levelup.wav`).

### 1.4. Схема данных (JSON / Pydantic)
```python
class RankTierConfig(BaseModel):
    min_question: int
    max_question: int
    rank_title: str       # "NPC", "Нормис", "Эрудит", "1% Гениев"
    rank_color: str       # Hex-код
    rank_icon: str        # Эмодзи или SVG идентификатор
    iq_label: str         # "IQ: 85", "IQ: 110", "IQ: 135", "IQ: 160+"

class RankBarProps(BaseModel):
    enabled: bool = True
    tiers: list[RankTierConfig]
```

## 2. Прогрессирующий стресс-таймер (Accelerating Stress Timer)

### 2.1. Концепция и психология
Монотонный таймер усыпляет бдительность. Постепенное сжатие времени создает нарастающий драматизм: вопросы становятся сложнее, а времени дается меньше. Зритель задерживает дыхание.

### 2.2. Визуальное поведение (Remotion)
- **Уровень 1 (Easy, Q1–3)**: длительность **3.0 сек**. Капсула спокойного лазурного цвета `#00A3FF`.
- **Уровень 2 (Medium, Q4–6)**: длительность **2.5 сек**. Капсула становится янтарно-оранжевой `#F59E0B` и начинает слегка дрожать на последней секунде.
- **Уровень 3 (Hard, Q7–9)**: длительность **1.8 сек** (экстремальный темп!). Капсула пульсирует ярко-алым `#EF4444`. По краям экрана появляется легкая пульсирующая виньетка «Panic Vignette», сигнализирующая о критической нехватке времени.
- **Общий хронометраж**: Строго $\le 50$ секунд на весь ролик (озвучка вопроса $\le 1.8$с + таймер + показ ответа 1.0с).

### 2.3. Аудио-эффекты (SFX)
- **Q1–3**: Стандартный размеренный тик часов (110 BPM, мягкий звук).
- **Q4–6**: Ускоренный механический секундомер (140 BPM, нарастающая громкость).
- **Q7–9**: Глухой, ускоряющийся стук сердца (Heartbeat 175 BPM) с высокочастотным писком за 0.4 секунды до ответа (`heartbeat_panic.wav`).

### 2.4. Схема данных (JSON / Pydantic)
```python
class StressTimerTier(BaseModel):
    tier_level: str               # "easy", "medium", "hard"
    think_duration_sec: float     # 3.0, 2.5, 1.8
    theme_color: str              # "#00A3FF", "#F59E0B", "#EF4444"
    sfx_file: str                 # "sfx/tick_calm.wav", "sfx/tick_fast.wav", "sfx/heartbeat.wav"
    panic_vignette: bool          # True только для hard
```

## 3. Комбо-стрик и шкала огня (Streak Fire / Combo Multiplier)

### 3.1. Концепция и психология
Элемент казуальных мобильных игр. Зритель вовлекается в поддержание серии побед: потерять серию на 7-м вопросе обидно, поэтому внимание обостряется до предела.

### 3.2. Визуальное поведение (Remotion)
- **Расположение**: Правый верхний угол (X = 920px, Y = 280px), симметрично левой лестнице ответов.
- **Индикация**:
  - `🔥 СТРИК: 1X` ... `🔥 СТРИК: 5X`.
  - При стрике 7+ пламя окрашивается в **синий цвет** (`#38BDF8`, Blue Fire Ultra Mode).
  - При каждом правильном ответе цифра комбо увеличивается с упругим spring-масштабированием (`scale: 1.35 -> 1.0`) и выбросом анимированных огненных искр.

### 3.3. Аудио-эффекты (SFX)
- Звук возгорания пламени (`fire_whoosh.wav`), где тональность (Pitch) увеличивается на +1 полутон с каждым следующим шагом стрика, создавая музыкальную эскалацию.

### 3.4. Схема данных (JSON / Pydantic)
```python
class ComboStreakConfig(BaseModel):
    enabled: bool = True
    fire_color_normal: str = "#FF4500"
    fire_color_ultra: str = "#00D2FF"
    ultra_threshold: int = 7
    sfx_pitch_step: float = 1.059463  # 1 полутон вверх за шаг
```

## 4. Байт на комменты и споры (Comment Trap & Controversy Bait)

### 4.1. Концепция и психология
Алгоритмы TikTok и Reels ранжируют видео в первую очередь по «скорости комментирования» (Comment Velocity). Зрителя провоцируют либо контринтуитивным фактом, где он считает ответ спорным, либо прямым вызовом на честность.

### 4.2. Механика в контенте
1. **Контринтуитивный вопрос (Q7 или Q8)**:
   - Пример: *«Какая самая сухая пустыня на Земле? 90% скажут Сахара, но правильный ответ — Антарктида!»*.
2. **Аутро-ловушка (Outro Hook, последние 3 секунды)**:
   - На экране крупная плашка:
     > **«Если у тебя 8 или 9 — ты 100% гуглил или соврал. Пиши реальный счет в комменты 👇»**
   - Это стимулирует зрителей массово писать: *«У меня честные 6!»*, *«Антарктида — это не пустыня, автор неуч!»*, запуская вирусные дебаты в комментариях.

### 4.3. Визуальное и звуковое поведение
- Всплывающий неоновый баннер призыва к дискуссии с анимированной иконкой комментов `💬`.
- Звук: акцент «dramatic buzzer / vine boom» + озвучка диктором провокационной фразы.

### 4.4. Схема данных (JSON / Pydantic)
```python
class CommentTrapConfig(BaseModel):
    enabled: bool = True
    trap_question_number: int = 8
    controversy_note: str         # "Большинство ошибается, считая Сахару..."
    outro_challenge_text: str     # "Если набрал 8+ — ты соврал. Пиши честный счет в комменты!"
    outro_audio_file: str | None = None
```

## 5. Бесшовный аудио-визуальный луп (Seamless Loop Hook)

### 5.1. Концепция и психология
Видео в ленте закольцовано. Если финальное предложение грамматически и интонационно завершается первым предложением ролика, зритель не замечает конца и пересматривает первые секунды заново, поднимая Retention Rate выше 100%.

### 5.2. Речевая связка (Prompt Engineering)
- **Фраза в самом начале (0:00)**:
  `«...и правильный ответ на первый школьный вопрос звучит так!»`
- **Фраза в самом конце (хронометраж 0:58)**:
  `«Только 1 человек из 100 сможет дойти до конца этой викторины...»`
- **Результат лупа**:
  *«Только 1 человек из 100 сможет дойти до конца этой викторины... [СКЛЕЙКА] ...и правильный ответ на первый школьный вопрос звучит так!»*

### 5.3. Визуальная бесшовность
- Фоновое видео зациклено встык без резкой смены ракурса.
- На 0-й секунде и на последней секунде экран свободен от всплывающих перекрывающих баннеров.

### 5.4. Схема данных (JSON / Pydantic)
```python
class SeamlessLoopConfig(BaseModel):
    enabled: bool = True
    intro_connector: str          # "...и первый вопрос звучит так:"
    outro_connector: str          # "Большинство завалится на старте, потому что..."
    audio_gapless_crossfade_ms: int = 80
```

## 6. Decoy Fake-Out (Детектор ложного ответа)

### 6.1. Концепция и психология
Когда все зрители хором мысленно дают самый популярный ошибочный ответ (стереотип), на экране на 0.4 секунды возникает этот ложный ответ, перечеркивается жирным красным крестом, и только потом показывается истина.
*Пример*: «Столица Австралии? ❌ Сидней! ➔ ✅ Канберра».

### 6.2. Визуальное поведение (Remotion)
- В момент Reveal:
  1. Кадр $T$: Появляется ложный ответ красным цветом со значком `❌`.
  2. Кадр $T+10$: Анимация красного штампа `STAMP_REJECT` и вибрация экрана (Screen Shake).
  3. Кадр $T+20$: Ложный ответ растворяется, на его месте взрывается зеленый истинный ответ `✅`.

### 6.3. Аудио-эффекты (SFX)
- Резкий звук ошибки (`wrong_buzzer_short.wav`), мгновенно сменяющийся триумфальным колокольчиком (`correct_bell.wav`).

### 6.4. Схема данных (JSON / Pydantic)
```python
class DecoyAnswer(BaseModel):
    has_decoy: bool = True
    decoy_text: str               # "Сидней"
    explanation_short: str        # "Самый частый ложный ответ"
```

## 7. Glitch Peek Hint (Слепая микро-подсказка)

### 7.1. Концепция и психология
На 8-м и 9-м вопросах зритель находится в ступоре. За 0.8 секунды до конца таймера на 8 кадров (около 130 мс) по центру экрана мелькает полупрозрачный размытый контур или первая буква ответа.
*Эффект*: Зритель думает: «Я что-то заметил!», ставит на паузу или пересматривает ролик еще раз, поднимая Watch Time.

### 7.2. Визуальное поведение (Remotion)
- Полупрозрачный слой с глитч-эффектом (`opacity: 0.4`, хроматическая аберрация RGB-split).
- Показ длится строго 8–10 кадров (недостаточно, чтобы прочитать без напряжения глаз).

### 7.3. Схема данных (JSON / Pydantic)
```python
class PeekHintConfig(BaseModel):
    enabled: bool = True
    hint_type: Literal["first_letter", "silhouette", "blur_unmask"] = "first_letter"
    duration_frames: int = 8
    frame_offset_before_reveal: int = 25
```

## 8. Anti-Cheat Callout (Челлендж честности)

### 8.1. Концепция и психология
На сложном 9-м вопросе появляется микро-плашка HUD: *«👀 Без паузы и Гугла! Смотри честно!»*. Это ломает четвертую стену, вызывает улыбку и уважение к ролику, провоцируя зрителя соревноваться честно.

### 8.2. Визуальное поведение
- Неоновый радарный бейдж в стиле киберпанк/HUD в нижнем углу экрана (`Scanline + Radar Pulse`).

### 8.3. Схема данных (JSON / Pydantic)
```python
class AntiCheatCallout(BaseModel):
    enabled: bool = True
    trigger_question: int = 9
    callout_text: str = "👀 БЕЗ ПАУЗЫ И ГУГЛА! ЧЕСТНЫЙ ТЕСТ"
```
