## 1. Автономный запуск через CLI

Для быстрой генерации ролика по произвольной теме в полностью автономном режиме:

```bash
# Генерация сценария, автоматический подбор картинок и сборка MP4
python -m videoanalizer.quiz.cli --mode visual_image_quiz --theme "Суперкары мира" --auto-approve --output output/visual_quiz_supercars.mp4
```

## 2. Пошаговое тестирование компонентов (Unit & Integration Tests)

### Тест 1: Валидация схемы данных и генерации сценария (`@script-service`)
Проверяет генерацию 10 вопросов, распределение сложности (3-3-3-1), отсутствие фразы «Вопрос номер 1» и наличие скрытого ответа на Q10.

```bash
pytest tests/unit/quiz/test_visual_quiz_script.py -v
```

### Тест 2: Сборка аудиоряда и синхронизация таймингов (`@audio-service`)
Проверяет нарезку аудио, синхронный таймер (2.0 сек), пословные метки субтитров и сведение микса с SFX.

```bash
pytest tests/unit/quiz/test_visual_quiz_audio.py -v
```

### Тест 3: Сквозной мок-рендер Remotion (`@orchestrator`)
Проверяет генерацию валидных пропсов Remotion и рендер 60fps тестового видеофрагмента.

```bash
pytest tests/integration/quiz/test_visual_quiz_orchestrator.py -v
```

## 3. Проверка через веб-интерфейс (UI & Approval)

1. Запустить веб-сервер VideoAnalyzer:
   ```bash
   python -m videoanalizer.main
   ```
2. Открыть в браузере `http://localhost:8000/quiz`.
3. В переключателе режимов выбрать **"Visual Image Quiz"**.
4. Ввести тему (или нажать «Случайная тема») и нажать **"Сгенерировать сценарий"**.
5. Проверить появившуюся плитку из 10 карточек:
   - Отображаются превью найденных картинок.
   - Нажать на превью для смены варианта из предложенных 4 кандидатов.
   - Нажать **"Утвердить все и отрендерить"**.
6. По завершении рендера проверить готовый ролик в плеере:
   - В интро (0:00–0:03.5s) картинки листаются в единой точке `x: 780, y: 450`.
   - В игре картинки появляются пружиной, таймер идет синхронно с репликой.
   - В лестнице 4 уровня с правильными заголовками.
   - Вопрос 10 скрывает ответ и призывает писать в комменты.
