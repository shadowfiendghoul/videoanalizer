## 1. Полнота пользовательских сценариев (User Stories)

- [x] CHK001 Приоритеты историй четко распределены (P1 для генерации сценария, хука интро и геймплея; P2 для интерстишлов; P3 для параметров).
- [x] CHK002 Каждый сценарий независим и содержит четкие критерии тестирования (Independent Test).
- [x] CHK003 Все сценарии расписаны в формате Given / When / Then с ожидаемыми результатами.
- [x] CHK004 Охвачено требование поддержки произвольных динамических тем (не только бренды одежды, но и автомобили, флаги, игры и т.д.).
- [x] CHK005 Зафиксировано требование к реплике вопроса №1 (без фразы «Вопрос номер один») и нумерации последующих вопросов.

## 2. Граничные случаи и отказоустойчивость (Edge Cases)

- [x] CHK006 Описано поведение при отсутствии или повреждении одного из 10 изображений (подстановка стилизованной заглушки).
- [x] CHK007 Описано поведение при длинных названиях предметов в строке лестницы (обрезка, масштабирование шрифта, защита от наложения на бокс).
- [x] CHK008 Учтены нестандартные пропорции изображений внутри бокса 380x380 px (`object-fit: contain`).
- [x] CHK009 Учтены задержки и ошибки API Gemini (экспоненциальный откат, повторные попытки, фоллбэк).
- [x] CHK010 Четко регламентированы безопасные зоны (safe zones) для мобильных вертикальных платформ (TikTok / Shorts / Reels).

## 3. Функциональные требования и архитектурные контракты

- [x] CHK011 Требования соответствуют Конституции проекта (Remotion 1080x1920 60fps, Pydantic v2, изоляция подсервисов).
- [x] CHK012 Четко специфицирован тайминг интро-хука (100–120 мс на кадр в единых координатах `x: 780, y: 450`).
- [x] CHK013 Специфицирована цветовая кодировка 4 уровней сложности (зеленый, желтый, красный, пурпурный).
- [x] CHK014 Специфицирован быстрый синхронный горизонтальный таймер (1.5–2.0 сек, `y: 1350`, 850 px) с градиентным цветовым переходом.
- [x] CHK015 Специфицированы интерстишлы (комментарии после Q3, репост после Q6) и механика коммент-ловушки на Q10.
- [x] CHK016 Определены уровни громкости звукового микса (TTS 0 dB, Flip -4 dB, Timer -6 dB, Ding -4 dB, BGM -18 dB).
- [x] CHK019 Специфицирован пайплайн автоподбора изображений через `/api/v1/quiz/search-image` с шагом ручного утверждения (approval).
- [x] CHK020 Специфицирована выделенная область пословных караоке-субтитров (`y: 1420..1500`) для всех голосовых реплик.

## 4. Измеримость критериев успеха (Success Criteria)

- [x] CHK017 Все критерии успеха измеримы (время генерации < 5 сек, точность флипа 100-120 мс, окно ролика 45-55 сек, безопасные зоны >= 400px / 120px).
- [x] CHK018 Критерии не завязаны на внутренние реализации деталей, а фокусируются на конечном результате для пользователя.
