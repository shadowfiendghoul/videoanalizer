## 1. Domain Entities & Schemas

### 1.1 TopicSuggestion
Represents an individual AI-generated topic optimized for short-form viral trivia.

| Field | Type | Required | Constraints | Description |
| :--- | :--- | :--- | :--- | :--- |
| `topic` | `str` | Yes | `min_length=3`, `max_length=70` | Catchy topic title for the quiz. |
| `category` | `str` | Yes | `min_length=2`, `max_length=40` | Niche category (e.g., "Анатомия", "Игры", "Парадоксы"). |
| `curiosity_hook` | `str` | Yes | `min_length=5`, `max_length=120` | Why this topic triggers curiosity and debate. |

### 1.2 BatchTopicList
Collection of topics returned by a single batch ideation request to Gemini.

| Field | Type | Required | Constraints | Description |
| :--- | :--- | :--- | :--- | :--- |
| `topics` | `list[TopicSuggestion]` | Yes | `min_length=1`, `max_length=25` | Array of diverse, non-overlapping topics. |

### 1.3 SingleTopicSuggestRequest & BatchTopicSuggestRequest

class SingleTopicSuggestRequest(BaseModel):

## 2. Queue Lifecycle & Status

### 2.1 BatchQueueItemStatus (Enum)

```python
class BatchQueueItemStatus(str, Enum):
    PENDING_GENERATION = "pending_generation"  # Script is being generated by AI
    PENDING_APPROVAL = "pending_approval"      # Generated, waiting for user review & approval
    QUEUED = "queued"                          # Approved, waiting in render queue
    RENDERING = "rendering"                    # Actively rendering in Remotion
    COMPLETED = "completed"                    # Render finished, MP4 ready for download
    FAILED = "failed"                          # Render or generation failed
    CANCELLED = "cancelled"                    # Cancelled by user
```

### 2.2 BatchQueueItem
Represents a single video throughout its batch lifecycle.

| Field | Type | Required | Constraints | Description |
| :--- | :--- | :--- | :--- | :--- |
| `item_id` | `str` | Yes | Starts with `bqi_` | Unique identifier for the item. |
| `index` | `int` | Yes | `ge=1`, `le=20` | Order index in the batch (1..N). |
| `topic` | `str` | Yes | `min_length=3`, `max_length=80` | Topic for this quiz video. |
| `challenge` | `QuizChallenge \| None` | No | Default `None` | 9-question structure once generated. |
| `status` | `BatchQueueItemStatus` | Yes | Default `pending_generation` | Current lifecycle state. |
| `progress_percent` | `int` | Yes | `ge=0`, `le=100`, default `0` | Live progress percentage. |
| `stage` | `str` | Yes | Default `""` | Human-readable status description. |
| `video_path` | `str \| None` | No | Default `None` | Local path to rendered MP4. |
| `download_url` | `str \| None` | No | Default `None` | Endpoint URL to download the video. |
| `error_message` | `str \| None` | No | Default `None` | Failure reason if status is `failed`. |
| `created_at` | `datetime` | Yes | UTC timestamp | Time item was created. |
| `updated_at` | `datetime` | Yes | UTC timestamp | Time of last state transition. |

### 2.3 BatchQueueState
The aggregate snapshot of active queue execution returned to the UI.

| Field | Type | Required | Constraints | Description |
| :--- | :--- | :--- | :--- | :--- |
| `batch_id` | `str` | Yes | Starts with `bq_` | Unique batch session ID. |
| `items` | `list[BatchQueueItem]` | Yes | `min_length=0` | All items in the batch. |
| `is_rendering` | `bool` | Yes | Default `False` | True if a video is actively rendering. |
| `active_item_id` | `str \| None` | No | Default `None` | ID of the item currently rendering. |
| `completed_count` | `int` | Yes | `ge=0` | Number of completed items. |
| `total_count` | `int` | Yes | `ge=0` | Total items in this batch. |
| `rate_limit_waiting` | `bool` | Yes | Default `False` | True if AI generation is paused for 15 RPM pacing. |
| `rate_limit_delay_sec` | `float` | Yes | Default `0.0` | Remaining seconds before next Gemini call. |

## 3. Batch Render Start Request Contract

```python
class BatchRenderStartRequest(BaseModel):
    """Payload to launch sequential Remotion rendering for approved items."""
    batch_id: str = Field(..., description="Batch identifier")
    items: list[BatchQueueItem] = Field(..., min_length=1, description="List of approved items with QuizChallenge")
    voice: str | None = Field(default=None, description="Voice override for speech synthesis")
    background_video: str | None = Field(default="random", description="Background video or 'random'")
    banner_video: str | None = Field(default=None, description="Optional banner video")
    background_music: str | None = Field(default=None, description="Background music track")
    background_music_volume: float = Field(default=0.18, ge=0.0, le=1.0)
    retention_enabled: bool = Field(default=True)
    rank_bar_enabled: bool = Field(default=True)
    stress_timer_enabled: bool = Field(default=True)
    streak_fire_enabled: bool = Field(default=True)
    comment_trap_enabled: bool = Field(default=True)
    uniquifier: VideoUniquifierConfig | None = Field(default=None)
    render_profile: RenderProfile = Field(default=RenderProfile.BALANCED)
```

## 4. State Transitions

```text
[Topic Generated]
       │
       ▼
[PENDING_GENERATION] ──(Progressive Gemini Script Gen, 5s delay)──► [PENDING_APPROVAL]
                                                                            │
                                                                   (User Reviews & Edits)
                                                                            │
                                                                 (User clicks "Запустить очередь")
                                                                            │
                                                                            ▼
                                                                        [QUEUED]
                                                                            │
                                                          (Worker picks item, Semaphore=1)
                                                                            │
                                                                            ▼
                                                                       [RENDERING]
                                                                      /           \
                                                          (Success)  /             \ (Error)
                                                                    ▼               ▼
                                                              [COMPLETED]       [FAILED]
                                                                    │               │
                                                              (Worker advances to next item)
```
